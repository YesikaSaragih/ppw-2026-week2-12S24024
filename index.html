Alur Proses Kerja (Workflow)

  1. Dekomposisi Data Layer: Memisahkan data statis ke dalam file JSON modular di folder `/data`.
  2. Data Access Layer (`js/api-service.js`): Membuat kelas pemanggil HTTP Fetch dengan `async/await` dan error handling.
  3. Dynamic Client-Side Rendering (`js/app.js`): Mengelola 4 UI States (Loading, Success, Empty, Error) dan merender kartu dinamis.
  4. Universal Dynamic Modal: Mengonfigurasi 1 modal tunggal untuk injeksi detail proyek secara dinamis.
  5. Form Dispatch & Profiling DevTools: Form POST asinkron, Toast, `localStorage`, dan analisis kinerja jaringan.
